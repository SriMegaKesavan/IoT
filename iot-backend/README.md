# IoT Backend Platform

A production-grade backend application for managing IoT devices, built using **Java**, **Spring Boot**, **PostgreSQL**, and **Docker**.  
This project follows industry standards and is designed to scale with future integrations like **MQTT**, **React frontend**, and **cloud deployment**.

---

## 🚀 Tech Stack

- Java 21+
- Spring Boot 4.x
- Spring Framework
- Spring Data JPA
- Spring Security
- Spring Boot Actuator
- PostgreSQL 15
- Docker
- Maven
- Lombok
- Jakarta Validation (Bean Validation)
